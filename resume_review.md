## 2. Smaller fixes

- **Seminar project title**: it says "Event Product Design", but the bullets describe event planning. If you designed the poster, banners, feed posts, or name tags, say so. That's design evidence. If you didn't, rename it "Student Seminar — Event Organizer".
- **Education**: add your expected graduation (e.g. "Expected 2028"). Employers use it to judge whether an internship fits. You could also add 2–3 relevant modules (e.g. Programming for Data Science, Statistics, Databases).
- **Remove duplicates**: the Social Media Management bootcamp appears under both *Education* and *Certification*. Keep it once, under *Certifications*.
- **Hidden characters**: the Google Docs export contains zero-width characters and tab runs between titles and dates. When I extracted the text, the way an ATS would, they showed up as junk. Line up dates with a right-aligned tab stop or a 2-column table instead of repeated tabs or spaces.
- **Header separators**: "Kuala Lumpur I +60…" uses a capital **I** as a separator. Use `|` or `·`.
- **Phone format**: write `+60 11-2569 2077` instead of `+60-112-5692-077`.
- **Languages**: state each level, e.g. *Indonesian (native), English (IELTS 6.5), Arabic (conversational / reading — be honest)*. For AI-training and translation jobs, the language list is your strongest selling point.
- **Grammar**: "achieved **an** 85% pass rate". "Standardized tests" may not be accurate for a school-level teacher; "end-of-term exams" is safer if that's what it was.
- **Teacher role**: cut it to 2 bullets and stress skills that transfer to remote work: explaining clearly, designing materials (did you make slides or worksheets in Canva? say so), and meeting deadlines.
- **Order of sections** for creative jobs: Header → Summary → Skills → Experience → Projects → Education → Certifications.

## 4. Portfolio checklist (most important for acceptance)

Your skills are good, but freelance clients hire from samples. Build this before you apply widely:

1. **Graphic design (6–8 pieces):** Instagram carousel, promo poster, logo or brand kit, YouTube thumbnail, presentation slide. Include the Lokality work, if they allow it.
2. **Video reel (30–60 sec):** a showreel of your best short-form edits plus 2–3 full examples (TikTok/Reels, 15–60 s each). Make a "before/after" edit if you don't have client work yet.
3. **Photography (8–12 photos):** one consistent set (product, food, portrait or event).
4. **Data project (1–2):** a small analysis or dashboard (e.g. Looker Studio or a Python notebook) on GitHub. **This repo can host it.**
5. Host the work on **Behance** (free; recruiters know it) or a well-organized **Google Drive** folder ("Anyone with link — Viewer"). Put the link in your CV header and LinkedIn "Featured".
